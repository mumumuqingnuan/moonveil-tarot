# 月隐塔罗 · Moonveil

78 张完整韦特塔罗、12 种牌阵、正逆位解读、洗牌与翻牌仪式、原创空灵音乐，以及结果长图保存。

GitHub Pages 发布地址：<https://mumumuqingnuan.github.io/moonveil-tarot/>

## 添加到桌面

打开网页，点击顶部的“添加到桌面”。

- Mac Safari：菜单栏“文件” → “添加到程序坞”。
- iPhone / iPad Safari：“分享” → “添加到主屏幕”。
- Chrome / Edge：使用地址栏的安装图标，或浏览器菜单的安装选项。

安装后显示深紫金色的月亮图标，以独立窗口打开。网站缓存基础界面及已浏览的牌面；首次打开和未缓存牌面的加载需要联网。

## 发布与本地运行

这是无需编译、无需服务器密钥的静态网站。在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root)，保存即可发布。

本地预览：在此目录运行 `python3 -m http.server 8080`，然后打开 `http://localhost:8080/`。

路径全部相对当前目录，可部署于 GitHub Pages 的项目子目录。问题只在当前页面内使用，不会发送到服务器。

牌面和音乐来源见 [ART-SOURCES.md](ART-SOURCES.md) 与 [assets/sources.json](assets/sources.json)。
